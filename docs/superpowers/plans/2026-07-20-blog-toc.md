# Blog Table of Contents Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A minimal sticky table of contents in the left gutter of blog posts, per the approved spec `docs/superpowers/specs/2026-07-20-blog-toc-design.md`.

**Architecture:** Heading data is extracted from the raw MDX source at module scope (a second `import.meta.glob` with `?raw`) and turned into `{ id, text }` pairs by a code-fence-aware parser. A shared `slugify` is used by both the parser and the `h2` MDX renderer so TOC hrefs and heading ids always agree. The TOC is a small component tree (nav rail → link items + scrollspy hook) composed in the route file.

**Tech Stack:** TanStack Start, React 19, Tailwind v4, motion/react, bun. No test framework exists in this repo — verification is via one-off `bun` scripts, `tsc --noEmit`, `vite build`, and visual checks in the user's own browser.

  text
    .toLowerCase()
    .replace(/[^a-z0-9\s-]/g, "")
    .trim()
    .replace(/\s+/g, "-");

- [ ] **Step 4: Implement `parseHeadings`**

Create `src/lib/parse-headings.ts`:

```ts
import { slugify } from "./slugify";

export type PostHeading = {
  id: string;
  text: string;
};

export const parseHeadings = (raw: string): PostHeading[] => {
  const headings: PostHeading[] = [];
  let inFence = false;

  for (const line of raw.split("\n")) {
    if (line.trim().startsWith("```")) {
      inFence = !inFence;
      continue;
    }
    if (inFence) continue;

    const match = /^##\s+(.+)$/.exec(line);
    if (match) {
      const text = match[1].trim();
      headings.push({ id: slugify(text), text });
    }
  }

  return headings;
};
```

Note: `/^##\s+/` matches h2 only — an `###` line has `#` (not whitespace) after `##`, so it does not match.

  eager: true,
  import: "default",
  query: "?raw",

export const getPostHeadings = (slug: string): PostHeading[] => {
  const path = Object.keys(modules).find(
    (key) => modules[key].frontmatter.slug === slug,

  if (!path) return [];

- [ ] **Step 1: Scrollspy hook**

Create `src/lib/use-active-heading.ts`:

```ts
import { useEffect, useState } from "react";

export const useActiveHeading = (ids: string[]): string | null => {
  const [activeId, setActiveId] = useState<string | null>(ids[0] ?? null);
  const idsKey = ids.join(",");

  useEffect(() => {
    const headingIds = idsKey === "" ? [] : idsKey.split(",");
    const headings = headingIds
      .map((id) => document.getElementById(id))
      .filter((el): el is HTMLElement => el !== null);
    if (headings.length === 0) return;

    const updateActive = () => {
      const line = window.innerHeight / 3;
      let current = headings[0].id;
      for (const el of headings) {
        if (el.getBoundingClientRect().top <= line) current = el.id;
      }
      setActiveId(current);
    };

    const observer = new IntersectionObserver(updateActive, {
      rootMargin: "0px 0px -66% 0px",
    });
    for (const el of headings) observer.observe(el);
    updateActive();

    return () => observer.disconnect();
  }, [idsKey]);

  return activeId;
};
```

Semantics (from spec): active = last heading whose top is above the upper third of the viewport; before the first section, the first item is active (also the SSR/initial state via `ids[0]`). The observer only triggers recomputation; `getBoundingClientRect` is the source of truth. `idsKey` keeps the effect stable across re-renders caused by `setActiveId`.

```tsx
import { AnimatedText } from "@/components/animated-text";
import { TocLink } from "@/components/blog/toc-link";
import type { PostHeading } from "@/lib/parse-headings";
import { useActiveHeading } from "@/lib/use-active-heading";

type TableOfContentsProps = {
  headings: PostHeading[];
};

export const TableOfContents = ({ headings }: TableOfContentsProps) => {
  const activeId = useActiveHeading(headings.map((h) => h.id));

  if (headings.length === 0) return null;

  return (
    <nav
      aria-label="Table of contents"
      className="absolute top-0 right-full bottom-0 mr-12 hidden w-[226px] xl:block"
    >
      <AnimatedText className="sticky top-24 space-y-3" delay={0.3}>
        {headings.map((heading) => (
          <TocLink
            id={heading.id}
            isActive={heading.id === activeId}
            key={heading.id}
            text={heading.text}
          />
        ))}
      </AnimatedText>
    </nav>
  );
};
```

```tsx
import { createFileRoute, notFound } from "@tanstack/react-router";
import { useMemo } from "react";

import { BlogPostBody } from "@/components/blog/blog-post-body";
import { BlogPostHeader } from "@/components/blog/blog-post-header";
import { GoBackLink } from "@/components/blog/go-back-link";
import { TableOfContents } from "@/components/blog/table-of-contents";
import { getPost, getPostHeadings, getPosts } from "@/lib/posts";

const BlogPost = () => {
  const { slug } = Route.useParams();
  const post = getPost(slug);
  const headings = useMemo(() => getPostHeadings(slug), [slug]);

  if (!post) return null;

  const { frontmatter, Component } = post;

  return (
    <main className="mx-auto max-w-2xl px-6 pt-24 pb-32">
      <BlogPostHeader date={frontmatter.date} title={frontmatter.title} />
      <div className="relative mt-10">
        <TableOfContents headings={headings} />
        <BlogPostBody Component={Component} />
      </div>
      <GoBackLink />
    </main>
  );
};

export const Route = createFileRoute("/blog/$slug")({
  loader: ({ params }) => {
    const posts = getPosts();
    const exists = posts.some((p) => p.slug === params.slug);
    if (!exists) throw notFound();
    return null;
  },
  component: BlogPost,
});
```

- Duplicate h2 texts produce identical ids (anchor jumps to first occurrence).
- Headings containing MDX expressions or inline markdown render their raw text in the TOC.
- No mobile/tablet TOC fallback.
